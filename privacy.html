Privacy Policy

Last updated: October 11, 2026

This application is a personal tool used only by its owner, Jialin Li, to access their own Google account data from their own computer.

What data is accessed

With the owner's permission, the application accesses the owner's Google Drive files and Gmail messages through Google's APIs, so the owner can read and manage them with command-line programs.

How data is used and stored

Data is used only to show and manage the owner's own files and email on the owner's own computer. Sign-in tokens are stored only on that computer. No data is sent to any server operated by the application's developer, and no analytics or tracking are used.

Sharing

No data is sold, shared with, or transferred to any third party.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
